Step by step

How to install

Windows

  1. Open TMS-Desktop-Setup-v1.6.3.exe.
  2. If Windows says "Windows protected your PC", click More info, then Run anyway.
  3. Click Install (or Update when TMS is already there).
  4. Open TMS and enter your license key the first time.

Mac

  1. Double-click the zip to unzip it.
  2. Right-click Install TMS Desktop.command, choose Open, then Open again.
  3. On newer Macs: System Settings › Privacy & Security › Open Anyway.
  4. Click Install, then enter your license key.

Android (tablet and phones)

  1. Tap the downloaded .apk file.
  2. If Android asks, allow Install unknown apps for your browser or Files app.
  3. Tap Install. Updating keeps your data.
  4. TMS Tablet: enter your license key and tap Activate.

One license key for every device. The same TMS license key works on Windows, Mac and Android tablets. Each device you activate uses one seat of your license. Activation needs the internet once.
